A one-line error message that tells the brutal truth: the server ate your file, blamed your Wi-Fi, and is pretending it never happened. main.ts writes that single line to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
